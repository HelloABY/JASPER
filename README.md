# J.A.S.P.E.R. 🚀

Welcome to my repository. This is basically my personal sandbox and public archive where I store everything I configure, learn, and break in the world of network and systems engineering.

---

## 🧠 The Philosophy: "Break it till it works, then break it again"

Some people see a network running smoothly and say, *"Perfect, don't touch it."* 
I look at it and think, *"Cool. Let's see what happens if I drop the default gateway, isolate the routing tables, and try to script the fix."*

I genuinely love messing around with under-the-hood configurations. I’m not just trying to memorize dry documentation for a certificate; I like setting up labs, testing how data packets behave, and figuring out how things actually connect. If a job has to be done manually twice, I'll probably try to write a quick script to handle it so I can move on to testing something else.

If you’re a fellow engineer or senior architect browsing this—welcome! Feel free to look through my setups, tear my configurations apart, or show me a better way to do things. I'm always looking to learn from people who have broken more servers than I have.

---

## 🛠️ What’s Inside the Folders

I treat this repo like an organized digital closet. Everything has its specific spot:

*   📂 **/projects** — Real network topologies and cloud setups I've messed around with (mostly Cisco, GNS3, and Azure practice environments).
*   📂 **/Tools** — Handy automation scripts, basic server hardening tasks, and PowerShell/Bash files I use to save time.
*   📂 **/Learn** — My personal study vault. Deep-dives, messy lab notes, and simplified cheat sheets for things like Azure administration.
*   📂 **/credentials** — The official receipts. My university Licence engineering degree papers and hands-on technical training certifications (like FTTH).
*   📂 **/portfolio** & **/resume** — The front-facing stuff, including my clean, up-to-date resume.

---

## 🧐 Oh, and what does JASPER mean?

The industry loves telling anyone entering the network or cloud field to "start at the absolute bottom resetting passwords for eternity." I built this organized space to show I'm aiming a bit higher out of the gate. 

The name stands for: **J**ust **A** **S**tep **P**ast **E**ntry-Level **R**oles. 

It's just a reminder to myself—and anyone looking at my profile—that I'm ready to skip the basic password resets, jump straight into real configurations, and get my hands dirty.
